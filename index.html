GitHub 連携（共有タブの編集に使用）

「共有」タブの予定をこのページから編集・追加するには、GitHub の個人用トークン（repo 権限）を設定します。設定はこの端末に保存されます。設定しなくても「個人」や追加タブの利用は可能です。

📅 カレンダーに登録（.ics）

カレンダータブについて
・「共有」…全員に見える予定。⚙️で GitHub 連携すると、このページから直接編集・追加・削除ができます（サイトへの反映まで1分ほど）。
・「個人」…Macカレンダーにある自分用の確定予定。
・「＋」でタブ（カレンダー）を自由に追加。追加したタブ・予定はその端末（ブラウザ）の中だけに保存され、他の人には見えません。

Mac / iPhone のカレンダーに登録するには、上の「カレンダーに登録」から trip.ics を開くか、Macカレンダーの「ファイル > 新規カレンダー購読」で
を購読してください。
