# tokyo-trip-2026 — 東京観光 予定表

2026/12/11(金)〜12/16(水) の東京観光の共有予定表（スマホ向け・静的サイト）。

## 見る / 共有する

GitHub Pages で公開: https://koppepandaisuki.github.io/tokyo-trip-2026/

- URL を知っている人なら誰でも見られます（無料・GitHub Pages）。
- スマホで開くと、日ごとの時間割で予定が見られます。

## カレンダータブ

- **全部** … すべての予定
- **共有** … 全員に見える予定（`data.js` で管理）
- **個人** … Macカレンダー由来の自分用の確定予定（ベテル・Zoomホスト）
- **＋** … カレンダータブを自由に追加（例：「家族」「友達」）
  - 追加したタブと、そこへ登録した予定は **その端末のブラウザ内だけ** に保存され、他の人には見えません。

## Mac / iPhone カレンダーに登録

ページ上部の「カレンダーに登録（.ics）」から `trip.ics` を読み込むか、
Macカレンダーの「ファイル > 新規カレンダー購読」で下の URL を購読すると、
カレンダー側で予定を確認・通知できます。

```
https://koppepandaisuki.github.io/tokyo-trip-2026/trip.ics
```

## 予定を編集する（ページ上から・推薦）

1. ページ右上の ⚙️ を開き、GitHub の個人用トークン（repo 権限）を1度だけ設定する（その端末に保存）。
2. 予定をタップして編集・削除、「＋ この日へ予定を追加」で追加。保存すると `data.js` と `trip.ics` が自動でコミットされ、全員の画面に反映される（1分ほど）。

## 予定を編集する（ファイルから）

1. `data.js` を編集する（日付 `days[].date`、予定 `items[]` の `start` / `end` / `title` / `place` / `cal`（「共有」「個人」など）/ `kind`）。

2. `node gen-ics.mjs` で `trip.ics` を再生成する。
3. コミットして push すればサイトに反映されます（GitHub 画面上の「鉛筆」編集でも可。その場合はPC側で `git pull` してから `node gen-ics.mjs` を実行）。

## 構成

- `index.html` / `style.css` / `app.js` — ページ本体（依存ライブラリなし）
- `data.js` — 予定データ（ここを編集）
- `gen-ics.mjs` / `trip.ics` — カレンダー用ファイルと生成スクリプト
